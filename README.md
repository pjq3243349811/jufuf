# 实用小工具 🧰

三个 Python 小脚本，不用联网，电脑上就能跑。

## 第一次用（只做一次）

1. 去 [python.org](https://www.python.org/downloads/) 下载安装 Python 3，安装时勾选 **"Add python.exe to PATH"**（Mac 直接装就行）。
2. 把这几个 `.py` 文件下载到电脑上同一个文件夹里。
3. 双击 `.py` 文件就能运行；如果双击没反应，就在这个文件夹里打开终端，输入 `python pomodoro.py`（换成对应文件名）。

## 三个工具

| 文件 | 干嘛的 |
|---|---|
| `pomodoro.py` | 番茄钟：25 分钟专注＋5 分钟休息，4 轮后长休息 15 分钟。备考、学习时用，手机放一边。 |
| `diet_log.py` | 饮食记录：记热量＋蛋白质/碳水/脂肪。选"记一笔"录入，选"看今天合计"看全天总数。数据存在同目录的 `diet_log.csv`，用 Excel 也能打开。 |
| `countdown.py` | 倒计时：国考报名、国考笔试、国开春季报名还剩几天，一眼看清。也可以临时加自己的倒计时。 |

## 小提示

- 都是纯标准库写的，不用装任何额外的包。
- 想改番茄钟时长/倒计时日期，直接用记事本打开 `.py` 文件，改最上面的数字就行，中文注释都标好了。
